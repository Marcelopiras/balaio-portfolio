# Balaio

Plataforma digital para gestão da colheita cafeeira, com controle de produção, equipes, acertos e pagamentos, inclusive com funcionalidades offline.

Projeto em desenvolvimento, com MVP funcional em homologação.

O Balaio Sustentável é uma evolução planejada para acompanhar indicadores socioambientais e apoiar a redução de desperdícios na colheita.

Este repositório apresenta o produto. O código-fonte da aplicação permanece privado.
